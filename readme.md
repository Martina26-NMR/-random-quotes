# 🎯 Random Quote Generator

A simple and responsive **Random Quote Generator** built using **JavaScript**, **HTML**, **CSS**, and **Bootstrap 5**. The app displays a new random quote each time you click the button.

## 📌 Features

- Displays a random quote on each click
- Responsive design using Bootstrap 5
- Clean and minimal UI
- Easy to customize and extend with more quotes or APIs

## 🚀 Technologies & Tools

- HTML5
- CSS3
- Bootstrap 5
- JavaScript (Vanilla)
- Media quaries
- OOCSS & BEM Methodology 
- Font Awesome


## 🖥️ Responsive Design

Works perfectly on all screen sizes and modern devices:
- 📱 Mobile phones
- 💻 Laptops
- 🖥️ Desktops
- 📲 Tablets
